# RealTime Data AI — Real-Time AI Data Intelligence Platform

An interactive, AI-powered data analysis and intelligence platform designed to process, clean, visualize, and export both structured and unstructured datasets using natural language commands.

🔗 **Live Demo:** [https://depuriroopesh.github.io/Ai-Data-analysis-/](https://depuriroopesh.github.io/Ai-Data-analysis-/)

---

## 🚀 Key Features

* **Multi-Format File Support:** Upload and manage both structured (`CSV`, `XLSX`, `JSON`) and unstructured (`PDF`, `TXT`) files in a centralized **Shared File Library**, or test workflows instantly using **Seed Demo Files**.
* **Natural Language Quick Commands:** Interact with your datasets using plain English prompts, including:
  * *"Clean structured dataset and remove missing values"*
  * *"Extract entities and convert document to table"*
  * *"Export cleaned dataset to Excel"*
  * *"Export executive summary to Word"*
* **End-to-End Agent Pipeline:** Dedicated workspaces covering the full data lifecycle:
  * **Agent Pipeline:** Automated AI task execution and prompt-driven data workflows.
  * **Data Workspace:** Inspect, filter, and transform uploaded files.
  * **Analytics & Charts:** Generate visual insights from processed datasets.
  * **Quality & Reports:** Evaluate data integrity and generate executive summaries.
  * **Export Hub:** Download cleaned data and reports in business-ready formats (`Excel`, `Word`, etc.).
* **Live Cloud Sync:** Connected to a **Global Real-Time Store (Firestore)** for real-time file synchronization and state management.

---

## 🛠️ Tech Stack

* **AI & Prompt Engineering:** Google Gemini API (Structured JSON outputs, entity extraction, summarization, and data cleaning prompts)
* **Frontend:** HTML5, CSS3, JavaScript (deployed via GitHub Pages)
* **Backend & Storage:** Firebase / Firestore (Real-Time Cloud Sync)

---

## 📖 How to Use

1. **Open the Live App:** Visit [RealTime Data AI](https://depuriroopesh.github.io/Ai-Data-analysis-/).
2. **Load Data:** Click **Upload File** to add your own `CSV`, `XLSX`, `JSON`, `PDF`, or `TXT` file, or click **Seed Sample Files** to load built-in demo datasets.
3. **Select a File:** Choose a file from the **Shared File Library** on the left panel.
4. **Run AI Commands:** Use the **Quick Commands** or enter custom natural language instructions to clean data, extract tables, generate charts, or export reports.
